Ajuda — Menus de Texto

Texto e HTML

Pode guardar texto normal ou HTML diretamente no snippet. Em editores rich-text, tags como <p>, <br>, <strong>, links e tabelas são inseridas como HTML.

Como usar

Depois de guardar uma alteração, clique com o botão direito numa página e abra Menus de Texto. Os itens finais inserem o texto no campo onde está o cursor.

Backups

Exportar backup guarda todos os menus e textos num ficheiro JSON. Importar backup valida o ficheiro e pede confirmação antes de substituir a configuração atual.
